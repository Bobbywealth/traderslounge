# TradersLounge Platform - Go-Live Checklist

## Overview

**TradersLounge** is a full-stack professional trading dashboard with a React frontend, Node.js/Express backend, Python signal scanner, and PostgreSQL database. The full deployment blueprint is in `render.yaml`.

---

## Current State

The `render.yaml` already defines all 5 services + 1 database:
- `bwts-postgres` — Managed PostgreSQL
- `traderslounge` — React frontend (static on Render)
- `traderslounge-api` — Node.js Express API (legacy, kept during cutover)
- `traderslounge-bwts-api` — Python read API (serves `/api/signals`, `/api/health`)
- `bwts-scanner` — Python background scanner worker
- `bwts-execution` — Python execution worker (paper mode by default)

## Go-Live Requirements

### 1. Rotate Exposed Secrets (CRITICAL — do first)

The previous `render.yaml` committed two production secrets to repo history. **Must rotate before merging**:

| Secret | Location in History | Action |
|--------|---------------------|--------|
| Postgres DSN password | Old `DATABASE_URL` env var | Render → Database → Rotate Password |
| Perplexity API key (`pplx-…`) | Old env var | Perplexity dashboard → revoke + regenerate |
| Twelve Data API key | Old `TWELVEDATA_API_KEY` in `marketData.js` | Get new key from twelvedata.com |

### 2. Set Network Allow-List (Render Dashboard)

Render → Environment → Network policy → Allowed hosts:

| Host | Purpose |
|------|---------|
| `api.twelvedata.com` | FX/gold OHLCV data |
| `api.binance.com` | Crypto OHLCV data |
| `nfs.faireconomy.media` | ForexFactory news feed |
| `api.tradelocker.com` | Live broker (only when `EXECUTION_MODE=live`) |
| `pypi.org`, `files.pythonhosted.org` | `pip install` |

### 3. Create Render Services

Connect this repo to Render and deploy from `render.yaml`. This provisions all services automatically.

### 4. Set `sync: false` Environment Variables (Render UI)

These are intentionally NOT in git — set in Render dashboard per service:

**All Python services:**
- `TWELVEDATA_API_KEY` — [Get from twelvedata.com](https://twelvedata.com) (free tier: 800 req/day)

**BWTS execution worker (only when ready for live):**
- `TRADELOCKER_API_KEY`
- `TRADELOCKER_API_SECRET`
- `TRADELOCKER_ACCOUNT_ID` (if multi-account)

**traderslounge-api (legacy Node API):**
- `PERPLEXITY_API_KEY` — [Get from perplexity.ai](https://perplexity.ai)
- `FINNHUB_API_KEY`
- `TWELVEDATA_API_KEY`

### 5. Verify Services are Running

```bash
# Health check
curl https://traderslounge-bwts-api.onrender.com/api/health

# Check signals
curl 'https://traderslounge-bwts-api.onrender.com/api/signals?limit=10'
```

Expected: `{"status":"ok","db_signals":N,"pairs":[...]}`

### 6. Watch Scanner Logs

In Render dashboard, tail `bwts-scanner` logs. Within 5 minutes (scan interval), you should see:

```
scanned XAUUSD → GOOD 52/80
scanned BTCUSD → NO_TRADE 22/80
```

### 7. Paper Trade Verification

Tail `bwts-execution` logs. When a STRONG signal arrives:

```
signal XAUUSD/STRONG → ACCEPTED (Order placed)
paper open XAUUSD BUY 0.02 lots @ 1900 SL=1880 TP1=1925
```

### 8. Test Kill Switch

From Render shell:
```bash
touch /var/run/bwts.kill
```
Next STRONG signal should be rejected. Remove file to resume.

### 9. Flip to Live Trading (ONLY after paper trading verified)

1. Verify TradeLocker response shapes in `scanner/tradelocker_broker.py`
2. Set `EXECUTION_MODE=live` on `bwts-execution`
3. Set TradeLocker credentials
4. Restart service
5. Watch first live trade carefully

### 10. Remove Legacy Node API (after Python API stable)

Once the Python read API has been running cleanly for a few days:

1. Change `VITE_API_URL` to `https://traderslounge-bwts-api.onrender.com`
2. Remove `traderslounge-api` block from `render.yaml`
3. Delete `server/` directory

## Original Exploration

**TradersLounge** is a full-stack professional trading dashboard platform with:

- **Frontend**: React 18 + TypeScript + Tailwind CSS + Vite + lightweight-charts + Recharts
- **Backend**: Node.js/Express API server with PostgreSQL database
- **Scanner System**: Python-based trading signal analysis engine (BWTS - Bobby Wealth Trading System)
- **Broker Integration**: TradeLocker, Binance with more brokers supported
- **AI Features**: Perplexity AI-powered signal generation

## API Integrations

### External APIs Used
1. **Perplexity AI** - Signal generation via `runStrategy()` in signals route
2. **TradeLocker** - Broker API (auth, positions, orders, history, execution)
3. **PostgreSQL** - Signal storage and retrieval
4. **Alpha Vantage, Finnhub, NewsAPI, Trading Economics** - Market data (mentioned in README)

### Internal APIs

#### Frontend → Backend (Express)
- `GET /api/signals` - Get all signals
- `POST /api/signals/refresh` - Generate new signals
- `DELETE /api/signals/cleanup` - Clean expired signals
- `GET /api/tradelocker/status` - Connection status
- `POST /api/tradelocker/auth` - Authenticate
- `GET /api/tradelocker/account` - Get account info
- `GET /api/tradelocker/positions` - Get positions
- `GET /api/tradelocker/orders` - Get orders
- `POST /api/tradelocker/execute-signal` - Execute trade
- `GET /api/market-data/:symbol` - Debug market data

#### Frontend → Python Scanner (BWTS)
- `GET /api/health` - Health check
- `GET /api/pairs` - Configured pairs
- `GET /api/config` - Public config (thresholds)
- `GET /api/signals` - List signals
- `GET /api/signals/:id` - Get signal by ID
- `GET /api/positions` - Open positions
- `GET /api/journal` - Closed trades
- `GET /api/journal/stats` - Journal statistics
- `GET /api/kill-switch` - Kill switch status
- `POST /api/kill-switch` - Toggle kill switch
- `POST /api/scans/refresh` - Request scan
